How does the merchant's server learn that a payment is paid? A registered letter is sealed, goes only to a real street address, and if nobody is home, the postman comes back. A webhook is that letter: the bank posts each payment event to the website's webhook address. It is signed, so the shop can tell a real event from a forged one. The address must lead to the public internet only, and it is checked again at the moment of connecting, so a webhook can never be turned against the bank's own network. A failed delivery is tried again, waiting longer each time, and after a while it is marked undelivered. The merchant can then ask for it again. Next: payments without a website.
