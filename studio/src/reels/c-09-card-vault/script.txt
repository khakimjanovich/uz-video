How do you keep a card number so that even a stolen database is useless? Inside the locked room, every coat goes into a sealed bag, and only one machine can open the bags. In the card zone, that machine is Vault. The card vault hands Vault the card number and keeps only the sealed value, and the key never leaves Vault. Each seal is tied to its own card, so a sealed value copied into another row will not open. To find a card again without opening any bag, Vault stamps each one with a fingerprint, the same for the same number: a blind index. The database itself refuses anything that is not sealed. If Vault is down, the card vault stops instead of guessing: it fails closed. A number is opened only to hand it to the card's network, and every use of card data is written down. And a card nobody has used for the bank's chosen time is removed. So a stolen copy of the database is just noise. Next: what a card's first digits tell you.
