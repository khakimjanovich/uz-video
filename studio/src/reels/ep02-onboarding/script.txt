Before a store takes its first payment, what does the bank check? The store registers, confirms its email, and uploads its company documents. The bank reviews them, signs a contract, and records the store's settlement account. Each website becomes a sales point with its own API key, and the bank checks that the site is real. But if one admin could switch a store on alone, one mistake is enough. So a second admin has to approve, and nobody can approve their own request. Now the store has an API key, so how does its server create a payment safely?
