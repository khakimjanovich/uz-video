How do you know the person signing up really owns that email address? Anyone can type anyone's email into a sign-up form. So the bank does what a postcard with a code does: it sends a one-time code to that address. Only someone who can read that inbox can type it back. That is email verification. The code works for a short time and for one sign-up. Too many wrong codes, and the sign-up is locked until the window ends, even if a new code is asked for. The password never touches ecom's own database: it goes straight to the login server. And if the store that keeps the codes is down, nothing is sent and nothing is accepted.
