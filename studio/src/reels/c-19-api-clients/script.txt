What should a merchant's server log in with? You never give a cleaner your own house keys. You give them a key of their own, which you can change without changing yours. A merchant's server gets the same: an API client, a login for a machine. Only an active merchant can create one. Its secret is shown exactly once, and ecom never keeps it. The server trades its id and secret for a short-lived token, and only that token reaches the payments API. When a secret may have leaked, the merchant rotates it: a new secret is issued, and the old one stops working at once. The owner's own login is never touched.
