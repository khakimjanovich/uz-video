Now the store has an API key, so how does its server create a payment safely? The simplest way is to send the amount and order number with the key. But anyone who copies that request can send it again. And if the network drops, the store's retry can create a second payment for the same order. So every request is signed with a secret, a timestamp and a one-time number, and a copied request is rejected. An idempotency key ties every retry to the first payment, and the bank returns a one-time payment link. The buyer opens that link, so what happens to their card next?
