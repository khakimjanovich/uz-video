A merchant may run several websites, so which one is allowed to take payments? A sales point is one website, with the return addresses where buyers come back after paying. Every return address must be an https page on the website's own domain, so a payment can never send a buyer somewhere else. Each sales point can carry the website's logo, which buyers see on the payment page. The logo goes to the same file service, in its own bucket: PNG or JPEG, up to one megabyte, and a new logo replaces the old file. A new sales point starts as a draft, and can't take payments yet. An admin checks the website and records the result. A failed check must list what is wrong, and every check is kept. The deal sets the card schemes and the refund window, and a longer window needs a reason and stays under a configured maximum. Switching it on needs an active merchant, a passed latest check, and at least one card scheme. Once it is live, the return addresses are frozen. A live website can be suspended and restored, and a closed one stays closed. Other modules ask one question: may this sales point take a payment right now, and the answer fails closed.
