What happens when a second module needs the same error handling and security as the first? We copy it, and now every fix must be made twice. So we extract the shared parts into our own Spring Boot starters. The error starter turns every failure into the same clean response. The security starter protects every endpoint in exactly the same way. The OTP and Redis starters give any module one-time codes and caching with a single dependency. Each starter configures itself, so a new module gets all of it for free. Same behavior, half the code, and every fix now lands in one place.
