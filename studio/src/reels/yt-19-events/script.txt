How do other systems learn that a payment was captured? If we save the payment and then publish an event, a crash in between loses the event forever. So the event is written to an outbox table, in the same transaction as the payment. A relay reads the outbox and publishes each event to Kafka. If the relay crashes, it simply resumes, and consumers ignore duplicates by their event ID. A webhook consumer delivers the news to the shop's server, with retries. Postgres stays the source of truth, and Kafka only carries the news. Next, taking payments without any website checkout at all.
