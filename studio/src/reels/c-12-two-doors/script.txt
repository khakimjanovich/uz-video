How many ways into the locked room should there be? The room has two kinds of visitor. Buyers' browsers come from the internet, to type a card into the card frame. And services from other units, like ecom, come from their own servers. One big proxy that opened every connection would see every caller's traffic in clear text. That box would be the most valuable box in the bank. So the room has two narrow doors, and nothing else listens. Think of a bank counter and a mail slot. The counter serves the public: it opens your envelope, and handles only a few kinds of request. The mail slot serves partners: it reads only the address on a sealed envelope, and drops it, still sealed, into the right box. The first door is the payers' door, and it is the counter. It opens the browser's encrypted connection, with a certificate that browsers trust. It passes on only the card frame's few paths. Every other path gets not found. It also limits how fast one payer can submit a card, but never how fast a page loads. Lesson thirteen comes back to that limit. The second door is the callers' door, and it is the mail slot. A caller's connection arrives encrypted, with the name of the service it wants written on the outside. The door reads only that name, and passes the connection on, still sealed. That is pass-through: the door never opens what it carries. The service behind it checks the caller's certificate and token itself, as lesson seven showed. Only four names pass: the card vault, the two adapters, and the room's login server. Any other name, or no name at all, is refused. So no door ever holds every caller's traffic in clear text. Now look at the mail slot's rules. It reads the name before anything else, and looks it up in one short list. Each name points to one service, and the last line sends everything else nowhere, because nothing listens there. Now check the counter on your laptop. Ask the payers' door for the card frame's script, and it answers two hundred. Ask it for a path inside the card vault, and it answers four oh four. On the laptop the door listens on port eight four four three; a server uses the usual port, four four three. A counter that handles only the frame, and a mail slot that never opens the post.
