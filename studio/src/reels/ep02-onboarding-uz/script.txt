Do'kon birinchi to'lovni qabul qilishidan oldin bank nimalarni tekshiradi? Do'kon ro'yxatdan o'tadi, emailini tasdiqlaydi va kompaniya hujjatlarini yuklaydi. Bank ularni ko'rib chiqadi, shartnoma tuzadi va do'konning hisob raqamini qayd etadi. Har bir sayt o'z API kaliti bilan savdo nuqtasiga aylanadi, bank esa sayt haqiqiyligini tekshiradi. Ammo bitta admin do'konni yolg'iz o'zi yoqa olsa, bitta xato yetarli. Shuning uchun ikkinchi admin tasdiqlashi shart, hech kim o'z so'rovini o'zi tasdiqlay olmaydi. Endi do'konda API kalit bor, uning serveri to'lovni qanday xavfsiz yaratadi?
