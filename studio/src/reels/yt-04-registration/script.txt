How do we know a new merchant really owns the email they typed? Anyone can type any address, so a sign-up alone proves nothing. So the partner module saves the merchant as pending, and sends a one-time code to that email. The code lives in Redis with a configured lifetime, and disappears when it expires. The email goes out through the email port, and locally it lands in Mailpit, where we can open it. The merchant types the code back, and only then is the email marked as verified. Wrong codes count against a configured limit, and too many lock the attempt. Resends are limited too, so nobody can flood an inbox. Every failure returns a clear error with a code, never a stack trace. Next, the merchant moves through a lifecycle, from pending to active.
