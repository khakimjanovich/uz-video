How do you know which network a card belongs to before you ask anyone? A phone number's first digits tell you the country, without telling you who you are calling. A card's first digits, its BIN, tell you the card network and the bank that issued the card. Each network publishes its list of BINs. The card zone copies those lists in, and refreshes them on a schedule. If a network does not answer, it keeps its old list rather than lose it. A lookup works like a phone code: the longest matching prefix wins. Before any network is asked to send a code to a buyer's phone, the card zone checks the card's network this way. So a card the shop does not accept is refused early, and no network is bothered. And this lookup only ever sees the first eight digits, never the whole number.
