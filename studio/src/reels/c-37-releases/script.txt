How do you know exactly what is running in a bank? A book's second edition never changes once it is printed, and you always say which edition you read. Releases work the same way. Each part of the system numbers its versions, so the number says breaking change, addition, or fix. A release is fixed once it is made, and everything is built from it, each with a list of every component inside. Every install pins the versions it runs, and every environment runs real releases, the laptop too. An upgrade is: back up, change the version, deploy, and check.
