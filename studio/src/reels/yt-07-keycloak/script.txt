Where do merchants' passwords and API keys actually live? Storing passwords yourself is a risk you don't need: one leak exposes them all. Keycloak holds the identities: a portal login for the merchant, and a machine client for their server. Each sales point gets its own client, and its token carries the merchant's ID. The client secret is shown only once, and the merchant can rotate it at any time. Our own secrets, like Keycloak's admin password, move out of environment files and into Vault. Every endpoint now checks the token before any business code runs. Next, the websites that will actually take the payments.
