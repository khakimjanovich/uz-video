How do thieves steal card numbers without breaking into any database? They add one line of script to a payment page, and copy every number as the buyer types it. That is web skimming. Our card frame is the bank's card reader on the shop's counter, and like a real reader, it has seals. Only the page its session names may hold the frame. The frame runs nothing but its own two files: its security policy forbids every other script. Each file carries its own fingerprint, so a changed file simply does not run. The frame hands back only the token and the masked number, and only to that one page. When the browser blocks something, it reports it, so a tampering attempt is seen. And the shop's page around the frame is watched too, because a skimmer there could still trick the buyer. Next: the two doors into the locked room.
