What happens inside the bank when it takes money from a card? The simplest way is to send one debit request straight to the processing center. But if two requests run at the same time, or the page is submitted twice, the card is charged twice. So before any money moves, the payment switches from open to authorizing in one atomic update, and only one request can win it. Every call to the processing center is written to an operation journal, with its result and reference numbers. The bank sends the debit through its terminal, identified by a merchant ID and a terminal ID. The debit runs as authorization and capture: first the money is held, then it is captured. When the processing center approves, the payment becomes captured, with its retrieval reference number.
