How do you install the same system on a laptop and in a bank? The cook uses one recipe in every kitchen; only where the ingredients come from changes. The install is the same on a laptop, a test server and production. Only the values differ, written down once for each environment. The card zone goes first, and ecom waits for its certificate. A preflight checks the machine first, and says exactly what to fix. Then Vault is set up, and every service's settings are written from it. The services start in order, and the install ends with a health check of both products. A later change is just a new value, applied the same way. Next: how a release is numbered and shipped.
