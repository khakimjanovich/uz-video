Who is allowed to switch a store on, or change its fee? The simplest way is that one admin changes it, and it takes effect at once. But that's neither professional nor secure: one wrong click changes real money. So every such change becomes a request that waits as pending. A second admin with an approver role approves or rejects it. Nobody can approve their own request, and for fees the database itself enforces that. If the fee changed while the request was waiting, approval is refused, so the checker approves exactly what they saw. Requests to switch a store on also expire if nobody answers within the configured time.
