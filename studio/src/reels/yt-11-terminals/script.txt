Which terminal does the processing center expect each debit to come through? It only accepts debits from terminals it already knows. So the terminal module keeps a registry: for each sales point and card scheme, one merchant ID and one terminal ID. Uzcard and Humo payments can use different terminals for the very same shop. Before every debit, the payment module resolves the terminal. No active terminal means no debit, and the payment fails closed. Every terminal change is logged, so an audit can see what was active, and when. Next, the card schemes themselves: talking to Uzcard and Humo.
